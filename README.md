# Library Management System

A console-based Library Management System developed using Core Java and Object-Oriented Programming (OOP) concepts.

## Features
- Add new books
- View all books
- Search books by ID
- Update book details
- Delete books
- Issue books
- Return books
- Validate user input and prevent duplicate book IDs

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- VS Code

## Project Structure
- `Book.java` — Stores book details and manages book status.
- `Library.java` — Implements book management operations.
- `Main.java` — Provides the menu-driven user interface.

## How to Run

Compile the Java files:

```bash
javac Book.java Library.java Main.java
```

Run the program:

```bash
java Main
```

## Learning Outcomes
This project demonstrates classes, objects, encapsulation, methods, ArrayList, loops, conditional statements, and basic input validation.
